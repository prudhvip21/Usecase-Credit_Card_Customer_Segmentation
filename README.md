# Credit Card Customer Segmentation

Group about 9,000 active credit card holders by usage behaviour to shape cross-sell and up-sell strategy.

## Approach

- Missing value imputation and scaling
- Dimensionality reduction with PCA
- KMeans and agglomerative clustering, with cluster profiling
